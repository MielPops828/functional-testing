# TC-001

**Название:** Проверка успешного расчет стоимости;
#### Предусловия:
- productId существует;
- есть authToken из 16 символов.
- count = 5, start = 0;
#### Шаги:
1. отправить GET запрос: /products/1/cost?authToken=abcd1234qwert567&count=5&start=0;
#### Ожидаемый результат:
- получен http-код: 200;
- получен ответ в json формате: { "cost": 100 }.

**Статус**: -

**Приоритет**: High
