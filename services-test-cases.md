# TC-001

Название: Проверка успешной отправки команды подключения услуги;
Предусловия:
- валидный запрос на подключение услуги;
Шаги:
- отправить REST запрос на подключение услуги в сервис A;
Ожидаемый результат:
- сервис A принимает запрос;
- сообщение отправлено в очередь RabbitMQ;
- сервис B получает сообщение;
- сервис B отправляет положительный ответ;
- сервис A получает ответ от сервиса B;
- статус услуги изменен после получения положительного ответа;
Статус: -
Приоритет: High

# TC-004

Название: Проверка асинхронной обработки запроса;
Шаги:
- отправить REST запрос в сервис A;
Ожидаемый результат:
- сервис A принимает запрос без ожидания ответа от сервиса B;
- ответ от сервиса A получен до ответа от сервиса B;
- изменение статуса происходит только после ответа от сервиса B;
Статус: -
Приоритет: High

# TC-005

Название: Проверка, что следующая команда не отправляется без ответа от сервиса B;
Шаги:
- отправить первый REST запрос;
- до получения ответа от сервиса B отправить второй REST запрос;
Ожидаемый результат:
- первая команда отправлена в очередь;
- вторая команда не отправляется в очередь до получения ответа на первую;
- после получения ответа первая команда завершается;
- затем отправляется вторая команда;
Статус: -
Приоритет: High

# TC-006

Название: Проверка соблюдения порядка выполнения команд;
Предусловия:
Шаги:
- отправить несколько REST запросов подряд (например: подключение, отключение, блокировка);
Ожидаемый результат:
- команды отправляются в очередь в порядке поступления;
- сервис B обрабатывает команды в том же порядке;
- ответы приходят в том же порядке;
Статус: -
Приоритет: High

# TC-007

Название: Проверка обработки ошибки от сервиса B;
Предусловия:
- сервис B настроен на возврат ошибки;
Шаги:
- отправить REST запрос в сервис A;
Ожидаемый результат:
- сообщение отправлено в очередь;
- сервис B возвращает ошибку;
- сервис A получает ответ с ошибкой;
- статус услуги не изменяется;
Статус: -
Приоритет: High

# TC-008

Название: Проверка поведения при отсутствии ответа от сервиса B;
Предусловия:
- сервис A доступен;
- сервис B недоступен;
- RabbitMQ доступен;
Шаги:
- отправить REST запрос;
Ожидаемый результат:
- сообщение отправлено в очередь;
- ответ от сервиса B отсутствует;
- следующая команда не отправляется;
- статус услуги не изменяется;
Статус: -
Приоритет: High
