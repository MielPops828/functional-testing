# Рецензирование требований (UI)

### Предусловие:
- Сохранить себе на Яндекс.Диск два любых файла
### Условие задачи:
- Реализована функция поиска по файлам и папкам.
- Поле поиска принимает любые буквы/цифры/символы.
- Результат работы функции - набор файлов и папок, удовлетворяющих запросу.
- Вслучае, если нет файлов, удовлетворяющих запросу, получено сообщение "В вашем Диске не найдено файлов или папок по запросу <.......>"
- Если файл находится в корзине - он так же может быть найден поиском.
---
# Результаты тестирования требований:
- есть ли ограничения на длину строки?
- как обрабатывается запрос, состоящий из пробелов?
- поддерживаются ли символы Unicode?
- есть ли сортировка результата?
- учитывается ли регистр?
- может результатом работы функции быть архив?
- происходит ли поиск по содержимому в файле, если не был найден файл или папка, удовлетворяющие условию?
- файл, находящийся в корзине, может быть найден тем же полем поиска на той же странице, где производится поиск существующих файлов на диске?
- в требованиях указано, что поиск осуществляется по файлам и папкам, однако часть требований описывает поведение только для файлов;
- не определено поведение для папок:
    - могут ли папки, хранящиеся в корзине, находиться через поиск?
    - как отображаются папки в результате поиска?
    - отображаются ли папки в результатах поиска наравне с файлами?
    - если есть папка и файл, содержащие одинаковое название, и этот файл хранится в папке, будет ли в результате поиска по имени файл отображаться отдельно от папки?
