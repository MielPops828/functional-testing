# Объект тестирования:
- REST API GET /products/{productId}/cost?authToken=&count=&start=
- параметры count, start, authToken
- методы: GET
- версия сборки: build v1.0.0
# Объем тестирования:
- В область тестирования входят:
	- валидация входных параметров;
	- http-коды (200, 401, 404, 500);
    - бизнес-логика расчета стоимости;
	- json-ответы ({ "cost": number }, { "errorMessage": "..." });
	- обработка ошибок;
	- безопасность (обработка попытки передачи SQL-запроса в качестве параметра).
- В область тестирования не входят:
	- UI;
	- база данных;
	- производительность и нагрузка;
	- внутренняя реализация бизнес-логики.
# Подход к тестированию:
- типы тестирования: функциональное тестирование, тестирование безопасности;
- уровни тестирования: системное тестирование;
- методы тестирования: эквивалентное разбиение, граничные значения, попарное тестирование, таблица принятия решений, исследовательское тестирование;
- инструменты: Postman, Swagger.
# Критерии начала тестирования:
- тестовый стенд доступен;
- документация утверждена;
- тестовые данные подготовлены;
